# EcoWatt AI

## AI-Based Energy Consumption Analysis and Anomaly Detection

EcoWatt AI is a machine learning and Streamlit-based web application that analyzes household energy consumption data, detects abnormal energy usage, predicts future consumption, and explains model predictions using SHAP (SHapley Additive Explanations).

---

## Features

- Data preprocessing and feature engineering
- Energy consumption prediction
- Anomaly detection using Isolation Forest
- SHAP-based model explainability
- Interactive Streamlit dashboard
- Performance evaluation
- User-friendly visualization of energy insights
